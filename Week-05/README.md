# Week 5 – AI PDF Chatbot Development

## Objective

Develop and improve an AI-powered PDF Chatbot using React, FastAPI, Retrieval-Augmented Generation (RAG), FAISS, and Large Language Models.

## Topics Covered

- RAG (Retrieval-Augmented Generation)
- PDF Processing
- Text Extraction
- OCR
- Text Chunking
- Embeddings
- FAISS Vector Search
- React UI/UX
- FastAPI REST API
- Docker
- Multi-LLM Integration

## Project Work

Developed and improved an AI PDF Chatbot that allows users to upload PDF documents and ask questions about their contents.

## Features Implemented

- PDF upload and processing
- Multiple PDF support
- PDF text extraction
- OCR support for scanned PDFs
- Text chunking
- HuggingFace embeddings
- FAISS vector database
- RAG-based question answering
- Source and page references
- Chat history
- Quick actions
- Search inside PDFs
- PDF page preview
- Light and dark themes
- Responsive React UI

## LLM Integration

Integrated three different Large Language Model providers:

- Google Gemini
- OpenAI GPT
- Ollama with Qwen 2.5 0.5B

## Docker Implementation

Containerized the project using Docker Compose with separate containers for:

- React frontend
- FastAPI backend
- Ollama

## UI/UX Improvements

- Redesigned the React interface
- Improved sidebar and model settings
- Added Lucide React icons
- Improved responsive layout
- Added better user feedback and loading states
- Improved document and chat presentation

## What I Learned

- RAG architecture
- Vector similarity search
- LLM integration
- PDF-based question answering
- REST API communication
- Docker containerization
- Multi-LLM application design
- React UI/UX development

## Result

Successfully developed a functional AI PDF Chatbot capable of answering questions from uploaded documents using multiple LLM providers.
